🧩 Tebak Kata AI

Mini game tebak kata berbahasa Indonesia. Kata rahasia, clue, dan teman diskusi semuanya dihasilkan secara langsung oleh Google Gemini.

🤖 Google Gemini ⚡ Node.js + Express 🎨 HTML · CSS · JavaScript 🎓 Latihan Hacktiv8

1 Tampilan Game

2 Jenis AI & Method LLM

🧠

Model AI

  • Google Gemini (LLM)
  • Model: gemini-3.6-flash
  • Diatur lewat GEMINI_MODEL di .env
📦

SDK

  • Library @google/genai
  • API key dari GEMINI_API_KEY
  • Key aman di server, tidak terlihat di browser
💬

Method

  • ai.models.generateContent()
  • Percakapan multi-turn (role user & model)
  • Riwayat chat dikirim ulang setiap bertanya

4 Temperature

🎲 Membuat Kata

1.0

Lebih kreatif, supaya kata dan clue bervariasi tiap ronde.

💬 Teman Diskusi

0.7

Seimbang: tetap ramah, tapi patuh aturan agar tidak membocorkan jawaban.

🏁 Komentar Akhir

0.8

Hangat dan ekspresif untuk ucapan selamat atau penghiburan.

5 System Instruction (Peran AI)

🎩

Game Master

  • Memilih 1 kata rahasia (4–10 huruf)
  • Membuat clue gaya teka-teki "Aku ..."
  • Membuat sapaan untuk pemain
  • Balasan wajib berformat JSON
🤝

Teman Diskusi

  • Tahu kata rahasia & data hurufnya
  • Dilarang menyebut atau mengeja jawaban
  • Maksimal 1 info huruf per jawaban
  • Singkat, santai, maksimal 3 kalimat
🎤

Pembawa Acara

  • Ucapan selamat sesuai nilai
  • Satu fakta menarik tentang kata
  • Menghibur jika pemain menyerah

6 Alur Permainan

MasukIsi nama dan pilih tema: Otomotif, Umum Indonesia, Umum Internasional, atau Campuran.
AI Menyiapkan KataGemini membuat kata, kategori, clue, dan sapaan dalam 1 request.
Baca ClueClue, kategori, dan jumlah huruf tampil di bawah kotak jawaban.
DiskusiTanya AI di chat, termasuk lewat tombol pertanyaan cepat.
JawabIsi kotak huruf lalu klik Jawab. Salah? AI memberi semangat.
HasilNilai tampil, AI memberi komentar, lanjut ke kata berikutnya.

7 Aturan Nilai

AksiNilai
Nilai awal setiap kata100%
Bertanya ke AI-10%
Tebakan salah-5%

  • Semakin banyak bertanya, semakin kecil nilai
  • Nilai minimum jika berhasil menjawab: 1%
  • Warna bar: 🟢 ≥70% · 🟡 ≥40% · 🔴 di bawahnya
  • Rata-rata nilai semua ronde tampil di header
  • Gagal terhubung ke AI? Nilai tidak dikurangi
